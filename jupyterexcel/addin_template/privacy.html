JupyterExcelAddin Privacy Policy

Last updated: September 14, 2026

JupyterExcelAddin connects Microsoft Excel to a configured Jupyter server so users can run Python notebook functions from Excel and receive their results. This policy describes information handled by the JupyterExcelAddin application and its JupyterExcel extension, rather than just the website hosting its files.

Information the application processes

  • Function inputs and results. Values you supply to a function or action are sent to the configured Jupyter server for execution. Results are returned to Excel. These values may contain personal information if you include it.
  • Connection and authentication information. The application uses your configured server address and access token to authenticate requests. A JupyterHub deployment may also use your username to identify your server and resources. The token is saved in Office runtime storage so the add-in can reuse it.
  • Notebook information. The server extension reads notebooks to discover exported functions and generate add-in resources, including function names, descriptions and parameter metadata. Notebook code may execute in the managed kernel when functions are initialized or called.
  • Diagnostics and technical information. Diagnostic records can include function names, timestamps, server addresses, request status, durations and error messages. Runtime console logging can include function arguments. Office, web servers and Jupyter may also record connection details such as IP addresses and request paths.

How information is used and where it goes

The application uses this information to authenticate connections, execute requested functions, return results, generate add-in resources and diagnose failures. Function requests go to the configured Jupyter server. Python code supplied by you or your server administrator may store information or send it to other services; review that code before processing personal information.

The server hosting the add-in receives requests for its HTML, JavaScript and other resources. Generated function descriptions and metadata are available to anyone who can access those hosted resources. Avoid putting personal or confidential information in published function descriptions.

Microsoft provides the Excel and Office runtime environment and handles information under its own privacy terms. Your Jupyter server and hosting providers may be operated by you, your organization or another provider. Their access, logging and retention practices also apply. Installing this software does not by itself identify who operates your configured server.

Storage and retention

Saved credentials and add-in settings persist in Office runtime storage until removed, replaced or cleared by the host. The add-in's stored diagnostic log is bounded to the most recent 200 entries and a size limit; older entries are removed as these limits are reached. This limit does not apply to separate Office console logs or server logs.

Notebook files, generated resources, kernel state, exported diagnostics and server logs can remain on the systems where they are created. Their retention depends on the relevant server or device administrator. The application does not impose a universal deletion period on these systems.

Your choices and privacy requests

You choose the server and the values submitted to its functions. You can disable optional Debug Log recording and clear its stored entries in the add-in's Debug Log pane. Separate runtime console or server logging may continue. Revoke an access token on the Jupyter server when it is no longer needed, and clear the add-in's stored data through the Office host where supported.

For access, correction or deletion of personal information held on a Jupyter server, contact that server's administrator. For personal information in support correspondence or questions about this application, contact the project maintainer below. Applicable privacy rights depend on your location and the organization responsible for processing your information.

Security

Access tokens authorize access to your Jupyter server. Keep them private and use trusted HTTPS endpoints. Logs and function arguments may contain personal information; review diagnostic exports before sharing them. No storage or transmission method can guarantee complete security.
